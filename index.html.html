Paso 2 — Crear el espacio para tu aplicación en GitHub

Entra a:

GitHub

  1. Inicia sesión.

  2. Arriba a la derecha pulsa +.

control-mantenimiento

  1. Selecciona Public.

  2. Marca Add a README file.

  3. Pulsa Create repository.

👉 No subas todavía el archivo.

Paso 3 — Subir tu aplicación

Entra al repositorio que acabas de crear.

  1. Pulsa Add file.

  2. Selecciona Upload files.

  3. Sube este archivo:

  1. Muy importante: cuando lo subas, cambia el nombre del archivo a:

index.html

  1. Baja hasta el final de la página.

  2. Pulsa Commit changes.

Paso 4 — Activar la página

Después:

  1. En tu repositorio entra en Settings.

  2. En el menú izquierdo busca Pages.

  3. En Build and deployment, selecciona:

    • Source: Deploy from a branch

    • Branch: main

    • Carpeta: / (root)

  4. Pulsa Save.

GitHub Pages publica sitios estáticos desde un repositorio y permite elegir una rama como fuente de publicación.
